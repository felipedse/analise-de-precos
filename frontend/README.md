# Front-end

React + Vite + TypeScript, com React Query, React Router e Tailwind. Veja o README da raiz.

```bash
npm install
npm run dev      # http://localhost:5173 (encaminha /api para o FastAPI em 127.0.0.1:8000)
npm test         # vitest
npm run lint     # oxlint
npm run build    # gera dist/, que o FastAPI serve em / quando existe
```
